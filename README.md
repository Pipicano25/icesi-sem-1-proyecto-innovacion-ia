# Proyecto I de Innovación Tecnológica en IA

**ICESI · Máster en Inteligencia Artificial Aplicada**

Desarrollo de un proyecto de innovación tecnológica aplicando inteligencia artificial bajo la metodología CRISP-ML(Q), desde la definición del problema hasta la entrega del producto.

## Contenido

| Carpeta | Descripción |
|---|---|
| `Sesion 1` – `Sesion 6` | Material y avances por sesión |
| `Clase` | Casos y proyectos de clase |
| `Entrgables Rubricas` | Rúbricas y entregables |
| `Informacion importante` | Documentos clave del proyecto |
| `Presentacion` | Diapositivas y presentaciones |

## Requisitos

- Python 3
- `pandas`, `numpy`, `scikit-learn`, `matplotlib`
